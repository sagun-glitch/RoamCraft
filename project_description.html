1. Executive Summary

RoamCraft is designed as a digital expedition dossier and field cartographer's trail map. Built with Node.js, Express, and Google Gemini, it streams personalized day-by-day itineraries live via Server-Sent Events (SSE) rendered across a topographic contour-line canvas with live compass bearing calculations.

2. Design Metaphor & Tokens

  • Field Permit Registration Slip: Left permit panel styled on parchment (#E8DCC0) with stamped toggle chips and handwritten field margin notes.
  • Topographic Map Canvas: Deep pine (#1B2A22) page background with SVG contour hairline rules (#C9B98C).
  • Animated Route Line & Compass Rose: Copper trail path (#B5622E) that animates across the map as itineraries compile, paired with a rotating live compass needle.
  • Typography: Header typography in Space Grotesk, data/body in IBM Plex Mono, and hand-lettered margin notes in Caveat.

3. Technical Stack & Architecture

Layer Technology Details

Frontend UI HTML5 / Vanilla CSS / ES6+ JS Field Expedition Dossier built with Space Grotesk, IBM Plex Mono & Caveat fonts, and Lucide Icons
Streaming Protocol Server-Sent Events (SSE) HTTP streaming protocol for progressive chunk rendering in client browser
